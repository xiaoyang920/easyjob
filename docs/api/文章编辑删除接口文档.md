# 文章编辑和删除接口文档

## 0. 获取文章列表（主界面/公开）

### 接口地址
```
GET /api/article/list
```

### 接口描述
获取公开发布的文章列表，支持分页和排序，用于主界面展示。不需要登录。

### 请求头
```http
Content-Type: application/json
```

### 请求参数
| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|---------|------|
| page | Integer | 否 | 1 | 页码 |
| size | Integer | 否 | 10 | 每页数量，最大100 |
| sort | String | 否 | latest | 排序方式：latest-最新发布，hottest-最热门（浏览数），liked-点赞最多 |
| categoryId | Long | 否 | null | 分类ID，筛选指定分类的文章 |
| keyword | String | 否 | null | 搜索关键词，在标题和摘要中搜索 |

### 请求示例
```http
GET /api/article/list?page=1&size=6&sort=latest
GET /api/article/list?page=1&size=10&sort=hottest
GET /api/article/list?page=1&size=20&categoryId=1001
GET /api/article/list?page=1&size=10&keyword=Spring%20Boot
```

### 后端实现要点
1. **只返回已发布的文章**：`status = 1`
2. **分页处理**：使用 MyBatis-Plus 的 `Page` 对象
3. **排序逻辑**：
   - `latest`：按 `publish_time DESC` 排序
   - `hottest`：按 `view_count DESC` 排序
   - `liked`：按 `like_count DESC` 排序
4. **JOIN 查询**：关联 `user_info` 表获取作者信息
5. **返回 PageVO**：不要直接返回 IPage，转换为 PageVO

### SQL 示例
```sql
SELECT 
    a.article_id,
    a.title,
    a.summary,
    a.cover_image,
    a.user_id,
    u.nick_name,
    u.avatar,
    a.view_count,
    a.like_count,
    a.comment_count,
    a.publish_time,
    a.tags,
    a.is_original
FROM article_info a
LEFT JOIN user_info u ON a.user_id = u.user_id
WHERE a.status = 1  -- 只查已发布的
  AND (a.title LIKE CONCAT('%', #{keyword}, '%') OR a.summary LIKE CONCAT('%', #{keyword}, '%'))  -- 关键词搜索
  AND (#{categoryId} IS NULL OR a.category_id = #{categoryId})  -- 分类筛选
ORDER BY 
  CASE WHEN #{sort} = 'latest' THEN a.publish_time END DESC,
  CASE WHEN #{sort} = 'hottest' THEN a.view_count END DESC,
  CASE WHEN #{sort} = 'liked' THEN a.like_count END DESC
LIMIT #{offset}, #{size}
```

### Controller 代码示例
```java
@GetMapping("/list")
public ResponseVO<PageVO<ArticleListVO>> getArticleList(
        @RequestParam(defaultValue = "1") Integer page,
        @RequestParam(defaultValue = "10") Integer size,
        @RequestParam(defaultValue = "latest") String sort,
        @RequestParam(required = false) Long categoryId,
        @RequestParam(required = false) String keyword) {
    
    // 限制 size 最大值
    if (size > 100) {
        size = 100;
    }
    
    // 调用 Service 获取分页数据
    PageVO<ArticleListVO> articlePage = articleService.getArticleList(page, size, sort, categoryId, keyword);
    
    return ResponseVO.success(articlePage);
}
```

## 1. 删除文章

### 接口地址
```
DELETE /api/article/{articleId}
```

### 接口描述
删除指定ID的文章（仅作者本人可删除）

### 请求头
```http
Authorization: Bearer <token>
Content-Type: application/json
```

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| articleId | Long | 是 | 文章ID |

### 请求示例
```http
DELETE /api/article/1998760353125687297
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 响应示例

**成功响应**：
```json
{
  "status": "success",
  "message": "删除成功",
  "data": null
}
```

**失败响应**（无权限）：
```json
{
  "status": "error",
  "code": 403,
  "message": "无权删除此文章"
}
```

**失败响应**（文章不存在）：
```json
{
  "status": "error",
  "code": 404,
  "message": "文章不存在"
}
```

### 后端实现要点
1. 验证用户登录状态（JWT Token）
2. 检查文章是否存在
3. **验证当前用户是否是文章作者**（重要：防止越权删除）
4. 执行软删除或硬删除（建议软删除，设置 `status = -1` 或 `is_deleted = 1`）
5. 返回操作结果

## 2. 修改文章

### 接口地址
```
PUT /api/article/{articleId}
```

### 接口描述
修改指定ID的文章（仅作者本人可修改）

### 请求头
```http
Authorization: Bearer <token>
Content-Type: application/json
```

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| articleId | Long | 是 | 文章ID |

### 请求体参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| title | String | 是 | 文章标题 |
| summary | String | 否 | 文章摘要 |
| content | String | 是 | 文章内容（富文本HTML） |
| coverImage | String | 否 | 封面图片URL |
| categoryId | Long | 否 | 分类ID |
| tags | String | 否 | 标签（逗号分隔） |
| isOriginal | Integer | 否 | 是否原创：0-否，1-是 |
| status | Integer | 否 | 文章状态：0-草稿，1-已发布 |

### 请求示例
```http

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**成功响应**：

```json
  "status": "error",
```

```json
{
```

### 后端实现要点
1. 验证用户登录状态（JWT Token）

## 4. Controller 示例代码（参考）

```java
@RestController
@RequestMapping("/api/article")
@Slf4j
public class ArticleController {
    
    @Autowired
    private ArticleService articleService;
    
    /**
     * 删除文章
     */
    @DeleteMapping("/{articleId}")
    public ResponseVO<?> deleteArticle(@PathVariable Long articleId) {
        // 获取当前登录用户ID
        Long currentUserId = UserContext.getUserId();
        
        // 调用 Service 删除
        articleService.deleteArticle(articleId, currentUserId);
        
        return ResponseVO.success("删除成功");
    }
    
    /**
     * 修改文章
     */
    @PutMapping("/{articleId}")
    public ResponseVO<?> updateArticle(
            @PathVariable Long articleId,
            @RequestBody ArticleUpdateDTO updateDTO) {
        
        // 获取当前登录用户ID
        Long currentUserId = UserContext.getUserId();
        
        // 调用 Service 更新
        articleService.updateArticle(articleId, updateDTO, currentUserId);
        
        return ResponseVO.success("修改成功");
    }
    
    /**
     * 获取文章编辑信息
     */
    @GetMapping("/{articleId}/edit")
    public ResponseVO<?> getArticleForEdit(@PathVariable Long articleId) {
        // 获取当前登录用户ID
        Long currentUserId = UserContext.getUserId();
        
        // 调用 Service 获取
        ArticleEditVO editVO = articleService.getArticleForEdit(articleId, currentUserId);
        
        return ResponseVO.success(editVO);
    }
}
```

## 5. Service 层逻辑（参考）

### 删除文章
```java
public void deleteArticle(Long articleId, Long currentUserId) {
    // 1. 查询文章
    Article article = articleMapper.selectById(articleId);
    if (article == null) {
        throw new BusinessException(404, "文章不存在");
    }
    
    // 2. 验证权限
    if (!article.getUserId().equals(currentUserId)) {
        throw new BusinessException(403, "无权删除此文章");
    }
    
    // 3. 删除（软删除）
    article.setStatus(-1); // 或者 article.setIsDeleted(1);
    articleMapper.updateById(article);
    
    // 或者硬删除：articleMapper.deleteById(articleId);
}
```

### 修改文章
```java
public void updateArticle(Long articleId, ArticleUpdateDTO updateDTO, Long currentUserId) {
    // 1. 查询文章
    Article article = articleMapper.selectById(articleId);
    if (article == null) {
        throw new BusinessException(404, "文章不存在");
    }
    
    // 2. 验证权限
    if (!article.getUserId().equals(currentUserId)) {
        throw new BusinessException(403, "无权修改此文章");
    }
    
    // 3. 更新字段
    article.setTitle(updateDTO.getTitle());
    article.setSummary(updateDTO.getSummary());
    article.setContent(updateDTO.getContent());
    article.setCoverImage(updateDTO.getCoverImage());
    article.setTags(updateDTO.getTags());
    article.setIsOriginal(updateDTO.getIsOriginal());
    article.setUpdateTime(LocalDateTime.now());
    
    // 4. 如果状态从草稿变为发布，更新发布时间
    if (article.getStatus() == 0 && updateDTO.getStatus() == 1) {
        article.setPublishTime(LocalDateTime.now());
    }
    article.setStatus(updateDTO.getStatus());
    
    // 5. 保存
    articleMapper.updateById(article);
}
```

## 7. 安全注意事项

1. **权限验证**：必须验证当前用户是否是文章作者，防止越权操作
2. **软删除**：建议使用软删除，避免数据丢失
3. **日志记录**：记录删除和修改操作日志
4. **事务处理**：确保修改操作的原子性
