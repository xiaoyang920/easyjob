# EasyJob 系统接口文档

## 1. 概述

本文档描述了EasyJob系统的API接口，包括认证、用户管理等功能。系统使用JWT进行身份验证，并提供了滑块式人机验证机制来增强安全性。

## 2. 技术栈

- 后端：Spring Boot
- 认证：JWT (HS512算法)
- 人机验证：滑块验证（前端实现）
- 数据存储：内存存储（演示用途）

## 3. 认证流程

### 3.1 登录流程

1. 用户在前端完成滑块验证
2. 用户提交用户名和密码到 `/api/auth/login`
3. 服务端验证用户凭据
4. 验证成功后返回JWT token
5. 前端在后续请求中携带token进行身份验证

### 3.2 Token结构

JWT token包含以下信息：
- userId: 用户ID
- subject: 用户ID字符串
- issuedAt: 签发时间
- expiration: 过期时间

## 4. API接口

### 4.1 认证接口

#### 4.1.1 用户登录

**接口地址**: `POST /api/auth/login`

**请求头**:
```
Content-Type: application/json
```

**请求参数**:
```json
{
  "username": "admin",
  "password": "password"
}
```

**响应成功**:
```json
{
  "token": "eyJhbGciOiJIUzUxMiJ9.xxxxx",
  "userId": 10001,
  "username": "admin"
}
```

**响应失败**:
```json
{
  "code": 401,
  "message": "用户名或密码错误"
}
```

### 4.2 用户接口

以下接口需要在请求头中携带JWT token:

```
Authorization: Bearer <token>
```

#### 4.2.1 获取用户信息

**接口地址**: `GET /api/user/info`

**请求头**:
```
Authorization: Bearer <token>
```

**响应成功**:
```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "userId": 10001,
    "nickname": "管理员",
    "role": "admin",
    "source": "ThreadLocal"
  }
}
```

#### 4.2.2 解析Token信息

**接口地址**: `GET /api/user/token-info`

**请求头**:
```
Authorization: Bearer <token>
```

**响应成功**:
```json
{
  "code": 200,
  "message": "Token解析成功",
  "data": {
    "userId": 10001,
    "username": null,
    "subject": "10001",
    "issuedAt": "2023-12-06T10:30:00.000+00:00",
    "expiration": "2023-12-13T10:30:00.000+00:00"
  }
}
```

## 5. 人机验证说明

系统采用滑块式人机验证，不依赖Redis或其他外部存储。验证过程完全在前端完成：

1. 用户拖动滑块到最右侧完成验证
2. 验证成功后登录按钮变为可用状态
3. 提交登录请求时会检查验证状态

## 6. 安全说明

1. JWT使用HS512算法签名，密钥长度满足安全要求
2. Token默认有效期为7天
3. 所有受保护接口都通过拦截器进行JWT验证
4. 使用ThreadLocal存储用户上下文信息，避免参数传递

## 7. 拦截器配置

系统配置了JWT拦截器，拦截规则如下：

- 拦截所有请求：`/**`
- 排除登录接口：`/api/auth/**`
- 排除静态资源：`.html`, `.css`, `.js`, 图片等
- 排除根路径：`/`

## 8. 前端页面

系统包含以下前端页面：

1. 普通登录页面：`/login.html`
2. 人机验证登录页面：`/captcha-login.html`
3. 注册页面：`/register.html`
4. 主页：`/index.html`
5. JWT测试页面：`/test-jwt.html`
6. ThreadLocal测试页面：`/test-threadlocal.html`
7. 个人空间：`/user-space.html`
8. 修改资料：`/edit-profile.html`

### 9.2 修改个人资料

**接口地址**: `PUT /api/user/update`

**接口描述**: 修改当前登录用户的个人资料

**请求头**:
```http
Authorization: Bearer <token>
Content-Type: application/json
```

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 | 校验规则 |
|--------|------|------|------|----------|
| nickName | String | 是 | 昵称 | 2-20个字符 |
| avatar | String | 否 | 头像URL | 合法的URL格式 |
| sex | Integer | 否 | 性别 | 0-女，1-男，2-未知 |
| birthday | String | 否 | 生日 | yyyy-MM-dd格式 |
| personIntroduction | String | 否 | 个人简介 | 最多500字符 |
| school | String | 否 | 学校 | 最多100字符 |
| noticeInfo | String | 否 | 空间公告 | 最多500字符 |
| theme | Integer | 否 | 主题 | 1-默认，2-暗黑，3-梦幻 |

**请求示例**:
```json
{
  "nickName": "新昵称",
  "avatar": "https://example.com/new-avatar.jpg",
  "sex": 1,
  "birthday": "1995-06-15",
  "personIntroduction": "个人简介",
  "school": "学校名称",
  "noticeInfo": "空间公告",
  "theme": 1
}
```

**响应成功**:
```json
{
  "status": "success",
  "code": 200,
  "message": "修改成功",
  "data": null
}
```

**响应失败**:
```json
{
  "status": "error",
  "code": 400,
  "message": "昵称长度应在2-20个字符之间",
  "data": null
}
```

**错误码说明**:

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误（昵称长度不符、昵称已被使用等） |
| 401 | 未登录或token失效 |
| 500 | 服务器内部错误 |

### 9.3 上传头像

**接口地址**: `POST /api/user/upload-avatar`

**接口描述**: 上传用户头像文件

**请求头**:
```http
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

**请求参数** (文件上传):

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | File | 是 | 图片文件（支持jpg/png/gif，最大5MB） |

**响应成功**:
```json
{
  "status": "success",
  "code": 200,
  "message": "上传成功",
  "data": {
    "avatarUrl": "https://example.com/avatars/xxx.jpg"
  }
}
```

**响应失败**:
```json
{
  "status": "error",
  "code": 400,
  "message": "文件格式不支持，请上传jpg/png/gif格式的图片",
  "data": null
}
```

**实现提示**:

1. **文件验证**：
   - 检查文件大小（不超过5MB）
   - 验证文件类型（image/jpeg, image/png, image/gif）
   - 检查文件名安全性

2. **文件存储**：
   - 生成唯一文件名（UUID + 原始扩展名）
   - 按照日期分目录存储（如：/avatars/2024/12/08/）
   - 可选：使用OSS对象存储服务（阿里云OSS、腾讯云COS等）

3. **图片处理**：
   - 压缩图片到合适大小（如800x800）
   - 生成缩略图（如200x200）
   - 去除图片EXIF信息

4. **数据库更新**：
   - 上传成功后，更新 `user_info` 表的 `avatar` 字段
   - 可选：删除旧头像文件

**前端调用示例**:

```javascript
// 上传头像
async function uploadAvatar(file) {
    const token = localStorage.getItem('token');
    const formData = new FormData();
    formData.append('file', file);
    
    try {
        const response = await fetch('/api/user/upload-avatar', {
            method: 'POST',
            headers: {
                'Authorization': `Bearer ${token}`
            },
            body: formData
        });
        
        const result = await response.json();
        
        if (result.status === 'success') {
            console.log('头像上传成功:', result.data.avatarUrl);
            // 更新页面头像显示
            document.getElementById('avatarImg').src = result.data.avatarUrl;
        } else {
            alert(result.message);
        }
    } catch (error) {
        console.error('上传失败:', error);
        alert('上传失败，请稍后重试');
    }
}
```
