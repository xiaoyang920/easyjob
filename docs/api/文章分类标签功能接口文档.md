# 文章分类标签功能接口文档

## 功能概述

- **主分类**：预设固定分类（如：技术、生活、随笔），**仅管理员可创建/编辑/删除**，每篇文章必选一个
- **多标签**：用户自由创建，每篇文章可添加多个标签
- **展示位置**：首页列表、文章详情、导航栏、发布/编辑页

**权限说明**：
- **普通用户**：可以选择现有分类，不能创建/修改分类
- **管理员**：可以在后台管理分类（增删改查）
- **所有用户**：可以自由创建和使用标签

## 1. 获取所有分类

**接口**: `GET /api/category/list`

**说明**: 获取所有启用状态的分类列表（包含二级分类结构）

**请求参数**: 无

**响应示例**:
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "categoryId": 1,
      "categoryName": "技术",
      "parentId": 0,
      "sortOrder": 1,
      "articleCount": 120,
      "children": [
        {
          "categoryId": 11,
          "categoryName": "前端开发",
          "parentId": 1,
          "sortOrder": 1,
          "articleCount": 50
        },
        {
          "categoryId": 12,
          "categoryName": "后端开发",
          "parentId": 1,
          "sortOrder": 2,
          "articleCount": 70
        }
      ]
    },
    {
      "categoryId": 2,
      "categoryName": "生活",
      "parentId": 0,
      "sortOrder": 2,
      "articleCount": 45
    },
    {
      "categoryId": 3,
      "categoryName": "随笔",
      "parentId": 0,
```

**说明**：

## 2. 标签搜索（输入联想）

**接口**: `GET /api/tag/search`

**说明**: 根据关键词搜索标签，用于发布文章时的标签输入联想

**请求参数**:
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| keyword | String | 是 | 搜索关键词 |
| limit | Integer | 否 | 返回数量，默认10 |

**请求示例**: `GET /api/tag/search?keyword=vue&limit=5`

**响应示例**:
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "tagId": 1,
      "tagName": "Vue3",
      "useCount": 120
    },
    {
      "tagId": 2,
      "tagName": "Vue Router",
      "useCount": 45
    },
    {
      "tagId": 3,
      "tagName": "Vuex",
      "useCount": 30
    }
  ]
}
```

**查询说明**：
- 使用模糊查询：`WHERE tag_name LIKE CONCAT('%', #{keyword}, '%')`
- 按使用次数降序排列：`ORDER BY use_count DESC`

## 5. 发布文章（新增字段）

**接口**: `POST /api/article/create`

**说明**: 创建文章时新增分类和标签字段

**请求头**: 
```
Authorization: Bearer {token}
```

**请求体**:
```json
{
  "title": "Vue3响应式原理解析",
  "content": "# 文章内容...",
  "summary": "本文深入讲解...",
  "coverImage": "/uploads/cover.jpg",
  "categoryId": 1,
  "tagNames": ["Vue3", "响应式", "源码解析"]
}
```

**字段说明**:
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| title | String | 是 | 文章标题 |
| content | String | 是 | Markdown内容 |
| summary | String | 否 | 摘要 |
| coverImage | String | 否 | 封面图 |
| categoryId | Integer | 是 | 分类ID（新增） |
| tagNames | String[] | 否 | 标签名称数组，不存在的标签自动创建（新增） |

**响应示例**:
```json
{
  "code": 200,
  "message": "发布成功",
  "data": {
    "articleId": 123
  }
}
```

## 数据库设计建议

### 1. 分类表 `article_category`
```sql
-- 你已有的表结构
CREATE TABLE `article_category` (
  `category_id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '分类ID',
  `category_name` VARCHAR(50) NOT NULL COMMENT '分类名称',
  `parent_id` BIGINT NOT NULL DEFAULT 0 COMMENT '父分类ID，0表示顶级分类',
  `sort_order` INT DEFAULT 0 COMMENT '排序值',
  `description` VARCHAR(200) COMMENT '分类描述',
  `article_count` INT DEFAULT 0 COMMENT '文章数量',
  `status` TINYINT DEFAULT 1 COMMENT '状态（1-启用，0-禁用）',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  INDEX idx_parent_id (parent_id),
  INDEX idx_status (status)
) COMMENT='文章分类表';

-- 初始数据示例
INSERT INTO `article_category` (category_name, parent_id, sort_order) VALUES
('技术', 0, 1),
('生活', 0, 2),
('随笔', 0, 3),
('职场', 0, 4),
('学习', 0, 5);
```

### 2. 标签表 `article_tag`
```sql
CREATE TABLE `article_tag` (
  `tag_id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '标签ID',
  `tag_name` VARCHAR(50) NOT NULL UNIQUE COMMENT '标签名称',
  `use_count` INT DEFAULT 0 COMMENT '使用次数',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间'
) COMMENT='文章标签表';

CREATE INDEX idx_use_count ON article_tag(use_count DESC);
CREATE INDEX idx_tag_name ON article_tag(tag_name);
```

### 3. 文章表 `article` 新增字段
```sql
ALTER TABLE `article` ADD COLUMN `category_id` BIGINT COMMENT '分类ID';
ALTER TABLE `article` ADD CONSTRAINT fk_article_category FOREIGN KEY (category_id) REFERENCES article_category(category_id);
CREATE INDEX idx_category_id ON article(category_id);
```

### 4. 文章标签关联表 `article_tag_relation`
```sql
CREATE TABLE `article_tag_relation` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '关联ID',
  `article_id` BIGINT NOT NULL COMMENT '文章ID',
  `tag_id` BIGINT NOT NULL COMMENT '标签ID',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  UNIQUE KEY uk_article_tag (article_id, tag_id)
) COMMENT='文章标签关联表';

CREATE INDEX idx_article_id ON article_tag_relation(article_id);
CREATE INDEX idx_tag_id ON article_tag_relation(tag_id);
```

## 前端调用示例

### 发布文章时选择分类和标签
```javascript
// 1. 获取分类列表
const categories = await request.get('/api/category/list')

// 2. 输入标签时搜索联想
const tags = await request.get('/api/tag/search', { params: { keyword: 'vue' } })

// 3. 获取热门标签
const hotTags = await request.get('/api/tag/hot', { params: { limit: 10 } })

// 4. 提交文章
await request.post('/api/article/create', {
  title: '文章标题',
  content: '内容...',
  categoryId: 1,
  tagNames: ['Vue3', '前端', '新标签']
})
```

### 按分类/标签筛选文章
```javascript
// 按分类筛选
const articles = await request.get('/api/article/list', {
  params: { categoryId: 1, page: 1, pageSize: 10 }
})

// 按标签筛选
const articles = await request.get('/api/article/list', {
  params: { tagIds: '1,2', page: 1, pageSize: 10 }
})
```

## 注意事项

1. **标签自动创建**：`tagNames` 传入的标签如果不存在，后端自动创建并关联
2. **标签去重**：相同标签名不区分大小写，后端需统一转换
3. **标签数量限制**：建议每篇文章最多5个标签
4. **分类必填**：发布文章时 `categoryId` 必须传值
5. **标签使用次数**：每次关联文章时 `tag.use_count` +1，取消关联时 -1
6. **分类权限**：只有管理员可以创建/编辑/删除分类，普通用户只能选择现有分类

## 管理员接口（后台分类管理）

### 1. 创建分类

**接口**: `POST /api/admin/category`

**权限**: 仅管理员

**请求头**:
```
Authorization: Bearer {admin_token}
```

**请求体**:
```json
{
  "categoryName": "新分类",
  "parentId": 0,
  "sortOrder": 10,
  "description": "分类描述"
}
```

**响应示例**:
```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "categoryId": 6
  }
}
```

### 2. 更新分类

**接口**: `PUT /api/admin/category/{categoryId}`

**权限**: 仅管理员

**请求体**:
```json
{
  "categoryName": "修改后的名称",
  "sortOrder": 5,
```

**响应示例**:
```json
{
  "code": 200,
  "message": "更新成功"

```

---

### 3. 删除分类

**接口**: `DELETE /api/admin/category/{categoryId}`

**权限**: 仅管理员

**响应示例**:
```json
{
  "code": 200,
  "message": "删除成功"
}
```

**删除逻辑**:
- 如果该分类下有文章，禁止删除，返回错误提示
- 如果有子分类，需要先删除子分类
- 或者设置为软删除（status=0）而不是物理删除
