# 草稿箱功能接口文档

## 1. 获取草稿列表

### 接口地址
```
GET /api/article/user/{userId}?status=0&page=1&size=10
```

### 接口说明
复用个人空间的文章列表接口，通过 `status=0` 参数筛选草稿。

### 请求头
```http
Authorization: Bearer <token>
Content-Type: application/json
```

### 请求参数
| 参数名 | 类型 | 位置 | 必填 | 说明 |
|--------|------|------|------|------|
| userId | Long | path | 是 | 用户ID |
| status | Integer | query | 是 | 文章状态（0=草稿, 1=已发布） |
| page | Integer | query | 否 | 页码（默认1） |
| size | Integer | query | 否 | 每页数量（默认10） |

### 请求示例
```http
GET /api/article/user/1998760353125687297?status=0&page=1&size=10
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 后端实现要点
1. **复用现有接口**：直接使用 `GET /api/article/user/{userId}` 接口
2. **添加 status 参数**：当 `status=0` 时过滤草稿
3. **默认查询所有状态**：如果没有 status 参数，查询所有已发布文章（status=1）
4. **按更新时间排序**：`ORDER BY update_time DESC`
5. **分页返回**：使用 MyBatis-Plus 的 `IPage<Article>`
6. **返回字段**：包括 articleId, title, summary, content(截取), coverImage, tags, viewCount, likeCount, collectCount, createTime, updateTime, publishTime, status, isOriginal, contentType

### 数据结构
返回的 `data` 对象包含：
- **records**: 文章列表数组
- **total**: 总记录数
- **size**: 每页数量
- **current**: 当前页码
- **pages**: 总页数

每篇文章包含：
- **articleId**: 文章ID（字符串）
- **title**: 标题
- **summary**: 摘要
- **content**: 内容（可截取前200字符）
- **coverImage**: 封面图
- **tags**: 标签
- **viewCount**: 浏览量
- **likeCount**: 点赞数
- **collectCount**: 收藏数
- **createTime**: 创建时间
- **updateTime**: 更新时间
- **publishTime**: 发布时间（草稿为 null）
- **status**: 状态（0=草稿, 1=已发布）
- **isOriginal**: 是否原创（1=原创, 0=转载）
- **contentType**: 内容类型（1=富文本, 2=Markdown）

### SQL 示例
```sql
SELECT 
    article_id,
    title,
    summary,
    LEFT(content, 200) as content,
    cover_image,
    tags,
    view_count,
    like_count,
    collect_count,
    create_time,
    update_time,
    publish_time,
    status,
    is_original,
    content_type
FROM article_info
WHERE user_id = #{userId} 
  AND status = #{status}  -- 0=草稿, 1=已发布
ORDER BY update_time DESC
LIMIT #{offset}, #{size}
```

### Service 层示例
```java
@Override
public IPage<Article> getUserArticles(Long userId, Integer status, Integer page, Integer size) {
    // 限制每页最多 20 条
    if (size > 20) {
        size = 20;
    }
    
    // 构建查询条件
    LambdaQueryWrapper<Article> wrapper = new LambdaQueryWrapper<Article>()
        .eq(Article::getUserId, userId)
        .orderByDesc(Article::getUpdateTime);
    
    // 如果指定了 status，添加过滤条件
    if (status != null) {
        wrapper.eq(Article::getStatus, status);
    } else {
        // 默认只查询已发布的文章
        wrapper.eq(Article::getStatus, 1);
    }
    
    // 分页查询
    IPage<Article> articlePage = articleMapper.selectPage(
        new Page<>(page, size),
        wrapper
    );
    
    return articlePage;
}
```

## 2. 发布草稿

### 接口地址
```
POST /api/article/{articleId}/publish
```

### 接口描述
将草稿文章发布为正式文章（将 status 从 0 改为 1）

### 请求头
```http
Authorization: Bearer <token>
Content-Type: application/json
```

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| articleId | Long | 是 | 文章ID |

### 请求示例
```http
POST /api/article/1998760353125687297/publish
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 响应示例

**成功响应**：
```json
{
  "status": "success",
  "message": "发布成功",
  "data": {
    "articleId": "1998760353125687297",
    "status": 1,
    "publishTime": "2025-12-11T10:00:00"
  }
}
```

**失败响应**（无权限）：
```json
{
  "status": "error",
  "code": 403,
  "message": "无权操作此文章"
}
```

**失败响应**（文章不存在）：
```json
{
  "status": "error",
  "code": 404,
  "message": "文章不存在"
}
```

**失败响应**（文章已发布）：
```json
{
  "status": "error",
  "code": 400,
  "message": "该文章已发布，无需重复操作"
}
```

### 后端实现要点
1. 验证用户登录状态
2. 检查文章是否存在
3. **验证当前用户是否是文章作者**（重要：防止越权操作）
4. 检查文章状态是否为草稿（status = 0）
5. 更新 `status = 1`，设置 `publish_time = 当前时间`
6. 更新 `update_time = 当前时间`

### 实现示例（Java）
```java
@PostMapping("/{articleId}/publish")
public ResponseVO<?> publishDraft(@PathVariable Long articleId) {
    // 获取当前用户ID
    Long currentUserId = UserContext.getUserId();
    
    // 查询文章
    Article article = articleMapper.selectById(articleId);
    if (article == null) {
        throw new BusinessException(404, "文章不存在");
    }
    
    // 验证权限
    if (!article.getUserId().equals(currentUserId)) {
        throw new BusinessException(403, "无权操作此文章");
    }
    
    // 检查状态
    if (article.getStatus() == 1) {
        throw new BusinessException(400, "该文章已发布，无需重复操作");
    }
    
    // 更新状态
    article.setStatus(1);
    article.setPublishTime(LocalDateTime.now());
    article.setUpdateTime(LocalDateTime.now());
    articleMapper.updateById(article);
    
    Map<String, Object> result = new HashMap<>();
    result.put("articleId", String.valueOf(articleId));
    result.put("status", 1);
    result.put("publishTime", article.getPublishTime());
    
    return ResponseVO.success("发布成功", result);
}
```

## 4. 注意事项

1. **复用现有接口**：直接使用 `GET /api/article/user/{userId}` 接口，无需新建
2. **status 参数**：通过 `status=0` 过滤草稿，`status=1` 过滤已发布文章
3. **默认行为**：如果没有 status 参数，默认返回已发布文章（status=1）
4. **分页结构**：返回 `data.records` 数组，包含 total, size, current, pages
5. **权限验证**：发布草稿时必须验证是否是文章作者
6. **时间更新**：发布时需要更新 `publish_time` 和 `update_time`
7. **索引优化**：添加 `(user_id, status, update_time)` 复合索引

```sql
-- 添加索引（如果还没有）
ALTER TABLE article_info 
ADD INDEX idx_user_status_update (user_id, status, update_time DESC);
```

## 5. 完整流程

```
用户点击“草稿箱”按钮
    ↓
跳转到 draft-box.html
    ↓
调用 GET /api/article/user/{userId}?status=0&page=1&size=10
    ↓
后端查询 article_info 表（user_id = xxx AND status = 0）
    ↓
返回分页数据：{ data: { records: [...], total, size, current, pages } }
    ↓
前端显示草稿列表（标题、摘要、浏览/点赞数、时间）
    ↓
用户点击“发布”按钮
    ↓
调用 POST /api/article/{id}/publish
    ↓
后端更新 status = 1, publish_time = 当前时间
    ↓
返回成功，重新加载草稿列表
```
