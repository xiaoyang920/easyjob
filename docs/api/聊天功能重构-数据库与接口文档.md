# 聊天功能重构 - 数据库与接口文档

## 一、数据库设计

### 1. 会话表（conversation）

```sql
-- 删除旧表（如果需要）
-- DROP TABLE IF EXISTS chat_message;
-- DROP TABLE IF EXISTS chat_session;

-- 会话表：一个会话只有一条记录
CREATE TABLE conversation (
    conversation_id BIGINT PRIMARY KEY COMMENT '会话ID',
    conversation_type TINYINT NOT NULL DEFAULT 1 COMMENT '会话类型：1=单聊，2=群聊',
    group_name VARCHAR(100) DEFAULT NULL COMMENT '群名称（群聊时使用）',
    group_avatar VARCHAR(255) DEFAULT NULL COMMENT '群头像（群聊时使用）',
    creator_id BIGINT NOT NULL COMMENT '创建者ID',
    last_message_id BIGINT DEFAULT NULL COMMENT '最后一条消息ID',
    last_message_content VARCHAR(500) DEFAULT NULL COMMENT '最后一条消息内容（冗余字段，提高查询效率）',
    last_message_time DATETIME DEFAULT NULL COMMENT '最后消息时间',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_creator (creator_id),
    INDEX idx_update_time (update_time DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='会话表';
```

### 2. 会话成员表（conversation_member）

```sql
-- 会话成员表：用户和会话的多对多关系
CREATE TABLE conversation_member (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    conversation_id BIGINT NOT NULL COMMENT '会话ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    unread_count INT NOT NULL DEFAULT 0 COMMENT '未读消息数',
    last_read_message_id BIGINT DEFAULT NULL COMMENT '最后已读消息ID',
    is_muted TINYINT NOT NULL DEFAULT 0 COMMENT '是否免打扰：0=否，1=是',
    is_top TINYINT NOT NULL DEFAULT 0 COMMENT '是否置顶：0=否，1=是',
    is_deleted TINYINT NOT NULL DEFAULT 0 COMMENT '是否删除会话：0=否，1=是',
    join_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '加入时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    UNIQUE INDEX uk_conversation_user (conversation_id, user_id),
    INDEX idx_user_deleted (user_id, is_deleted),
    INDEX idx_user_update (user_id, update_time DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='会话成员表';
```

### 3. 消息表（message）

```sql
-- 消息表
CREATE TABLE message (
    message_id BIGINT PRIMARY KEY COMMENT '消息ID',
    conversation_id BIGINT NOT NULL COMMENT '会话ID',
    sender_id BIGINT NOT NULL COMMENT '发送者ID',
    message_type TINYINT NOT NULL DEFAULT 1 COMMENT '消息类型：1=文本，2=图片，3=语音，4=视频，5=文件',
    content TEXT NOT NULL COMMENT '消息内容',
    extra_data JSON DEFAULT NULL COMMENT '扩展数据（图片尺寸、文件大小等）',
    reply_to_message_id BIGINT DEFAULT NULL COMMENT '回复的消息ID',
    status TINYINT NOT NULL DEFAULT 0 COMMENT '消息状态：0=正常，1=撤回，2=删除',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    INDEX idx_conversation_time (conversation_id, create_time DESC),
    INDEX idx_sender (sender_id),
    INDEX idx_reply (reply_to_message_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='消息表';
```

### 4. 数据迁移（可选）

如果需要从旧表迁移数据：

```sql
-- 迁移会话数据
INSERT INTO conversation (conversation_id, conversation_type, creator_id, last_message_content, last_message_time, create_time)
SELECT DISTINCT 
    LEAST(user_id, other_user_id) * 10000000000 + GREATEST(user_id, other_user_id) as conversation_id,
    1 as conversation_type,
    LEAST(user_id, other_user_id) as creator_id,
    last_message,
    last_message_time,
    NOW()
FROM chat_session
GROUP BY LEAST(user_id, other_user_id), GREATEST(user_id, other_user_id);

-- 迁移会话成员数据
INSERT INTO conversation_member (conversation_id, user_id, unread_count)
SELECT 
    LEAST(user_id, other_user_id) * 10000000000 + GREATEST(user_id, other_user_id) as conversation_id,
    user_id,
    unread_count
FROM chat_session;
```

## 二、接口文档

### 基础信息

- **Base URL**: `/api/chat`
- **认证方式**: JWT Token (Header: Authorization)
- **响应格式**: 
```json
{
    "code": 200,
    "message": "success",
    "data": {}
}
```

---

### 1. 获取会话列表

**接口**: `GET /api/chat/conversations`

**描述**: 获取当前用户的所有会话列表

**请求参数**: 无

**响应数据**:
```json
{
    "code": 200,
    "data": [
        {
            "conversationId": "1234567890",
            "conversationType": 1,
            "otherUserId": "9876543210",
            "otherUserName": "张三",
            "otherUserAvatar": "/uploads/avatar/xxx.jpg",
            "lastMessage": "你好",
            "lastMessageTime": "2024-01-20T10:30:00",
            "unreadCount": 3,
            "isMuted": false,
            "isTop": false
        }
    ]
}
```

**字段说明**:
| 字段 | 类型 | 说明 |
|------|------|------|
| conversationId | String | 会话ID |
| conversationType | Integer | 会话类型：1=单聊，2=群聊 |
| otherUserId | String | 对方用户ID（单聊） |
| otherUserName | String | 对方昵称（单聊）/ 群名称（群聊） |
| otherUserAvatar | String | 对方头像（单聊）/ 群头像（群聊） |
| lastMessage | String | 最后一条消息内容 |
| lastMessageTime | String | 最后消息时间 |
| unreadCount | Integer | 未读消息数 |
| isMuted | Boolean | 是否免打扰 |
| isTop | Boolean | 是否置顶 |

```json
        "lastMessage": null,
        "lastMessageTime": null,
        "unreadCount": 0
    }
}
```

### 3. 获取消息列表

**接口**: `GET /api/chat/messages`

**描述**: 获取会话的消息列表（分页，按时间倒序）

**请求参数**:

|------|------|------|------|
| conversationId | Long | 是 | 会话ID |
| lastMessageId | Long | 否 | 上一页最后一条消息ID（用于分页） |
| size | Integer | 否 | 每页数量，默认20 |

**响应数据**:
```json
{
    "code": 200,
    "data": {
        "records": [
            {
                "messageId": "111222333",
                "conversationId": "1234567890",
                "senderId": "1",

                "status": 0,
                "replyToMessageId": null,
                "replyToContent": null
            }
        ],
        "hasMore": true
    }
}
```

**字段说明**:
| 字段 | 类型 | 说明 |
|------|------|------|
| messageId | String | 消息ID |
| conversationId | String | 会话ID |
| senderId | String | 发送者ID |
| senderName | String | 发送者昵称 |
| senderAvatar | String | 发送者头像 |
| messageType | Integer | 消息类型：1=文本，2=图片 |
| content | String | 消息内容 |
| createTime | String | 发送时间 |
| status | Integer | 状态：0=正常，1=撤回 |
| replyToMessageId | String | 回复的消息ID |
| replyToContent | String | 回复的消息内容（截取前50字） |
| hasMore | Boolean | 是否还有更多历史消息 |

### 5. 标记会话已读

**接口**: `POST /api/chat/conversation/{conversationId}/read`

**描述**: 标记会话消息已读，清空未读数

**请求参数**: 
- Path参数: conversationId (会话ID)

**响应数据**:
```json
{
    "code": 200,
    "message": "success"
}
```

---

### 6. 删除会话

**接口**: `POST /api/chat/conversation/{conversationId}/delete`

**描述**: 删除会话（软删除，只对当前用户生效）

**请求参数**: 
- Path参数: conversationId (会话ID)

**响应数据**:
```json
{
    "code": 200,
    "message": "success"
}
```

---

### 7. 撤回消息

**接口**: `POST /api/chat/message/{messageId}/recall`

**描述**: 撤回消息（2分钟内可撤回）

**请求参数**: 
- Path参数: messageId (消息ID)

**响应数据**:
```json
{
    "code": 200,
    "message": "success"
}
```

**错误码**:
- 400: 消息不存在
- 403: 只能撤回自己的消息
- 400: 超过2分钟无法撤回

## 三、后端实现要点

### 1. 创建会话逻辑

```
1. 接收 targetUserId
2. 查询是否已存在两人的会话：
   SELECT c.conversation_id 
   FROM conversation c
   INNER JOIN conversation_member cm1 ON c.conversation_id = cm1.conversation_id AND cm1.user_id = 当前用户ID
   INNER JOIN conversation_member cm2 ON c.conversation_id = cm2.conversation_id AND cm2.user_id = targetUserId
   WHERE c.conversation_type = 1
3. 如果存在，返回该会话
4. 如果不存在：
   - 生成 conversation_id（雪花算法）
   - 插入 conversation 表
   - 插入两条 conversation_member 记录
5. 返回会话信息（关联查询对方用户信息）
```

### 2. 发送消息逻辑

```
1. 验证会话存在且当前用户是成员
2. 生成 message_id（雪花算法）
3. 插入 message 表
4. 更新 conversation 表的 last_message 相关字段
5. 更新所有成员（除发送者）的 unread_count + 1
6. 返回消息详情
7. （可选）WebSocket 推送给在线成员
```

### 3. 查询会话列表逻辑

```sql
SELECT 
    c.conversation_id,
    c.conversation_type,
    c.last_message_content,
    c.last_message_time,
    cm.unread_count,
    cm.is_muted,
    cm.is_top,
    -- 获取对方信息（单聊）
    other_cm.user_id as other_user_id,
    u.nick_name as other_user_name,
    u.avatar as other_user_avatar
FROM conversation c
INNER JOIN conversation_member cm 
    ON c.conversation_id = cm.conversation_id 
    AND cm.user_id = #{currentUserId}
    AND cm.is_deleted = 0
-- 关联对方成员（单聊）
LEFT JOIN conversation_member other_cm 
    ON c.conversation_id = other_cm.conversation_id 
    AND other_cm.user_id != #{currentUserId}
    AND c.conversation_type = 1
-- 关联对方用户信息
LEFT JOIN user_info u ON other_cm.user_id = u.user_id
ORDER BY cm.is_top DESC, c.last_message_time DESC
```

### 4. 标记已读逻辑

```
1. 验证当前用户是会话成员
2. 更新 conversation_member 表：
   UPDATE conversation_member 
   SET unread_count = 0, 
       last_read_message_id = (SELECT MAX(message_id) FROM message WHERE conversation_id = #{conversationId})
   WHERE conversation_id = #{conversationId} 
     AND user_id = #{currentUserId}
```

## 四、前端修改要点

### 1. API 调整

| 旧接口 | 新接口 |
|--------|--------|
| GET /chat/sessions | GET /chat/conversations |
| POST /chat/session/create | POST /chat/conversation/create |
| GET /chat/messages?sessionId=xxx | GET /chat/messages?conversationId=xxx |
| POST /chat/send | POST /chat/message/send |
| POST /chat/session/{id}/read | POST /chat/conversation/{id}/read |

### 2. 字段映射

| 旧字段 | 新字段 |
|--------|--------|
| sessionId | conversationId |
| fromUserId | senderId |
| toUserId | （移除，通过会话成员判断） |

### 3. 消息判断逻辑

```javascript
// 旧：判断是否是自己发的消息
msg.fromUserId === myUserId

// 新：判断是否是自己发的消息
msg.senderId === myUserId
```
