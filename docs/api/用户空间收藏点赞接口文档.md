# 用户空间收藏和点赞接口文档

## 1. 获取用户收藏的文章列表

### 接口信息
- **请求路径**: `GET /api/action/user/{userId}/collect`
- **接口描述**: 获取指定用户收藏的文章列表（分页）
- **是否需要登录**: 是

### 请求参数

#### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | Long | 是 | 用户ID |

#### Query 参数
| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | Integer | 否 | 1 | 页码，从1开始 |
| size | Integer | 否 | 20 | 每页数量，最大100 |

### 请求头
```
Authorization: Bearer {token}
Content-Type: application/json
```

### 请求示例
```http
GET /api/action/user/123/collect?page=1&size=20
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 响应参数
| 参数名 | 类型 | 说明 |
|--------|------|------|
| status | String | 响应状态：success/error |
| code | Integer | 响应码：200成功，其他失败 |
| message | String | 响应消息 |
| data | Object | 分页数据对象 |
| ├─ records | Array | 文章列表 |
| │  ├─ articleId | String | 文章ID（字符串格式） |
| │  ├─ title | String | 文章标题 |
| │  ├─ coverImage | String | 封面图片URL |
| │  ├─ summary | String | 文章摘要 |
| │  ├─ authorName | String | 作者昵称 |
| │  ├─ authorAvatar | String | 作者头像 |
| │  ├─ viewCount | Integer | 浏览量 |
| │  ├─ likeCount | Integer | 点赞数 |
| │  ├─ collectCount | Integer | 收藏数 |
| │  ├─ publishTime | String | 发布时间 |
| │  └─ collectTime | String | 收藏时间 |
| ├─ total | Long | 总记录数 |
| ├─ size | Integer | 每页数量 |
| └─ current | Integer | 当前页码 |

## 4. 前端调用示例

### 获取收藏列表
```javascript
async function loadCollectedArticles() {
    const userId = localStorage.getItem('userId');
    const token = localStorage.getItem('token');
    
    try {
        const response = await fetch(`/api/action/user/${userId}/collect?page=1&size=20`, {
            method: 'GET',
            headers: {
                'Authorization': `Bearer ${token}`,
                'Content-Type': 'application/json'
            }
        });
        
        const result = await response.json();
        
        if (result.status === 'success') {
            console.log('收藏列表:', result.data.records);
            console.log('总数:', result.data.total);
        }
    } catch (error) {
        console.error('加载失败:', error);
    }
}
```

## 5. 注意事项

1. **权限验证**：建议添加权限验证，确保用户只能查看自己的收藏和点赞列表
2. **分页限制**：建议限制 `size` 参数的最大值（如100），防止一次查询过多数据
3. **性能优化**：对于高频查询，可以考虑添加 Redis 缓存
4. **ID 格式**：文章 ID 使用字符串格式返回，避免 JavaScript 精度丢失
5. **时间格式**：统一使用 `yyyy-MM-dd HH:mm:ss` 格式
6. **空列表处理**：返回空数组而不是 null，方便前端处理
