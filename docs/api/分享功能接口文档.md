# 分享功能接口文档

## 1. 记录分享行为

### 接口信息
- **接口路径**: `/api/share/record`
- **请求方式**: `POST`
- **接口描述**: 记录用户分享文章/评论的行为

### 请求参数

#### Headers
```
Authorization: Bearer {token}
Content-Type: application/json
```

#### Body参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| articleId | Long/String | 是 | 文章ID |
| articleUserId | Long/String | 是 | 文章作者ID |
| commentId | Long/String | 否 | 评论ID（有值代表分享评论，无值代表分享文章） |
| shareType | Integer | 否 | 分享方式：0-复制链接 1-二维码 2-海报（默认0） |

#### 请求示例

**分享文章**：
```json
{
  "articleId": "123456",
  "articleUserId": "10001",
  "shareType": 0
}
```

**分享评论**：
```json
{
  "articleId": "123456",
  "articleUserId": "10001",
  "commentId": "789012",
  "shareType": 0
}
```

### 响应参数

#### 成功响应
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "shareCount": 156
  }
}
```

#### 字段说明
| 字段名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码 |
| message | String | 响应消息 |
| data.shareCount | Integer | 分享文章时返回文章的总分享数 |

## 2. 后端处理逻辑

### user_action 表处理
1. 查询是否已存在该用户对该文章/评论的分享记录
2. **如果已存在**：更新 `action_time` 字段
3. **如果不存在**：插入新记录

### 分享数处理
- **分享文章**：`article.share_count + 1`（每次都+1，后续再做风控）
- **分享评论**：可选增加 `article_comment.share_count`

### ActionType 枚举
```java
ARTICLE_SHARE(5, "分享文章"),
COMMENT_SHARE(6, "分享评论")
```

### 伪代码
```java
@PostMapping("/share/record")
public Result recordShare(@RequestBody ShareDTO dto) {
    Long userId = UserContext.getUserId();
    Integer actionType = dto.getCommentId() != null 
        ? ActionTypeEnum.COMMENT_SHARE.getCode()   // 6
        : ActionTypeEnum.ARTICLE_SHARE.getCode();  // 5
    
    // 1. 查询是否已存在记录
    UserAction existing = userActionMapper.selectOne(
        new LambdaQueryWrapper<>(UserAction.class)
            .eq(UserAction::getUserId, userId)
            .eq(UserAction::getArticleId, dto.getArticleId())
            .eq(UserAction::getCommentId, dto.getCommentId())
            .eq(UserAction::getActionType, actionType)
    );
    
    if (existing != null) {
        // 2. 已存在，更新 actionTime
        existing.setActionTime(LocalDateTime.now());
        userActionMapper.updateById(existing);
    } else {
        // 3. 不存在，插入新记录
        UserAction userAction = new UserAction();
        userAction.setUserId(userId);
        userAction.setArticleId(dto.getArticleId());
        userAction.setArticleUserId(dto.getArticleUserId());
        userAction.setCommentId(dto.getCommentId());
        userAction.setActionType(actionType);
        userAction.setActionCount(dto.getShareType());  // 记录分享方式
        userAction.setActionTime(LocalDateTime.now());
        userActionMapper.insert(userAction);
    }
    
    // 4. 分享文章时，分享数+1
    if (dto.getCommentId() == null) {
        articleMapper.incrementShareCount(dto.getArticleId());
    }
    
    // 5. 返回最新分享数
    Article article = articleMapper.selectById(dto.getArticleId());
    return Result.success(Map.of("shareCount", article.getShareCount()));
}
```

## 前端使用说明

### 调用分享功能

```javascript
// 点击分享按钮时
async function shareArticle() {
  const url = window.location.href
  
  try {
    // 1. 复制链接到剪贴板
    await navigator.clipboard.writeText(url)
    
    // 2. 调用后端接口记录分享
    const res = await request.post('/share/record', {
      articleId: article.value.articleId,
      shareType: 0  // 0-复制链接
    })
    
    if (res.code === 200) {
      shareCount.value = res.data.shareCount
      showShareSuccess()  // 显示成功提示
    }
  } catch (error) {
    console.error('分享失败:', error)
  }
}
```

### 功能特点

1. **自动复制链接**：点击分享按钮自动将文章链接复制到剪贴板
2. **记录分享数**：后端记录分享次数，可用于统计和排行
3. **友好提示**：复制成功后显示提示框（3秒后自动消失）
4. **降级处理**：如果后端接口失败，前端仍显示复制成功
5. **兼容性处理**：如果 `navigator.clipboard` 不可用，使用备用方案

---

## 注意事项

1. **登录校验**：记录分享行为需要用户登录
2. **频率限制**：建议对同一用户、同一文章的分享记录做去重（如1分钟内只记录一次）
3. **统计精度**：分享数可以用于文章热度排序
4. **HTTPS要求**：`navigator.clipboard.writeText()` 在HTTPS环境下才可用
5. **备用方案**：提供了 `document.execCommand('copy')` 作为降级方案
