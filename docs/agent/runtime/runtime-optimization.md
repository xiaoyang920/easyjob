# RAG、可靠任务与记忆预算改造

本次实施前三项优化：独立检索并发、记忆与文章索引的可靠任务、摘要和事件记忆提取的 Token 预算。主代理仍采用决策、执行、观察循环。

## RAG

查询改写和条件解析结束后，同时启动平台检索与联网搜索。平台内部多个向量、关键词查询共享服务级 Semaphore，默认最多 4 个在途请求，单路请求超时 30 秒。平台来源的 MySQL 公开状态和版本校验、精排仍按依赖执行；两路完成后统一检查相关性和生成引用。

RRF 按原查询顺序合并结果，不按请求完成顺序合并，保持相同输入的排序和去重语义。任一路发生硬错误或调用被取消，未完成的兄弟任务也取消并等待退出。联网失败保留错误报告；权限和来源版本校验继续作为硬门禁。当前并发额度约束平台子查询，不代表整个服务的全局流量限制。

## 持久化后台任务

迁移 `005_durable_jobs.sql` 只增加 `agent_background_job`、`article_index_outbox` 两张表；应用启动检查结构，迁移由 `python -m app.migrate` 显式执行并校验版本与校验和。

### 事件记忆

正式运行完成时，助手消息与提取任务在同一 MySQL 事务提交，使用消息 ID 构造幂等任务键。前台完成回复后不再读取整段前端历史或创建易丢失的内存提取任务。

后台每个 Agent 实例有一个执行者，每 2 秒空闲轮询。任务领取使用行锁，领取后有 120 秒租约和执行代次标识，单次处理限时 90 秒。事件提取的模型调用最多 45 秒。服务关闭保留未完成任务，租约过期后重新领取；旧执行者提交记忆前必须通过租约校验。

事件记忆落库、对应 ES 索引任务和提取任务完成状态一起提交。写入去重在锁定所属会话后执行，检查包括已失效记录，防止同一内容被重新提取恢复。候选索引按记忆 ID 幂等覆盖；重试前重新读取 MySQL 当前状态，已失效、删除的记录执行 ES 删除。Main 的同步记忆变更也在事务里登记索引任务，既有 `user_memory_change` 同步回执与检索前补偿机制保留。

提取按任务携带的消息上界读取最近最多 128 条消息，独立查询用户轮次数；不把任务调度后新增的对话混入本次提取。提取冷却在成功提交后设置。

### 文章索引

文章发布、修改、删除事务内写 Outbox，不在事务提交后的回调里直接依赖 MQ 发送。Relay 每秒处理一个限长批次，使用 30 秒投递租约；等待 broker confirm 最多 5 秒，开启 mandatory 并检查 returned message。

Broker 确认仅表示投递成功，Outbox 进入 `dispatched`。消费者在文章锁保护下读取当前状态，执行分块、索引、版本校验与过期块清理，完成后才标记 `completed`。重复已完成消息跳过嵌入与索引；消费者失败、确认丢失、进程中断时，未完成 Outbox 在至少 60 秒后重新投递。旧删除消息继续读取文章当前状态，避免删除已重新发布内容。

这提供至少一次投递与幂等处理，不承诺远程调用只发生一次。应用插入时显式使用 UTC 计算任务可执行时间，避免数据库本地时区导致任务延迟。

### 重试与维护

记忆任务和文章 Outbox 默认最多尝试 8 次。错误后等待 5、10、20、40、80、160、300 秒，继续失败后进入 `dead`，不会无限重试。租约回收也计入次数；`dead` 保留错误类型供排查。当前没有自动告警和已完成任务定期归档。

可以查询两张表的 `status`、`attempts`、`last_error` 和可执行时间查看积压。排除故障后，对明确选定的死任务将 `status` 改为 `pending`、`attempts` 改为 0、`available_at` 改为 `UTC_TIMESTAMP(6)`，清空租约即可恢复；只处理经核对的任务 ID。文章消费者幂等，记忆索引始终读取当前有效状态。

## 摘要与事件提取

Main 整体 96K 触发评估、24K 近期软预算、4K 摘要上限与无收益跳过策略保留。摘要提示词移除旧的 500 字限制，建议长度按历史规模的约四分之一计算，上限 4K Token；按用户确认事实、有效要求、已确认决策、取消变更、未完成事项组织摘要，并区分助手推测。

事件记忆提取包含真实 Prompt 和工具 Schema 后，输入最多 16K Token，输出最多 2K Token。选择最近完整用户与助手轮次，不再固定取 20 条。输出最多 8 条事件，每条最多 1,000 字符，重要度约束为 0–1；后台事件提取不能写画像、约束或决策。

若最新完整轮次本身无法放入预算，任务明确失败并按限次规则处理，不静默截断或发送超预算输入。当前没有对此类巨型轮次进行分段提取。本地 Token 计数为估算，保留模型请求安全余量；仍需单独评测摘要事实保留率。
