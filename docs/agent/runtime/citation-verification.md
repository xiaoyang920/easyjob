# 引用来源复核

回答生成与依据核验是独立模型调用。核验选择了正文未引用的来源时，只能说明引用绑定不一致，不能单凭这个结果认定正文错误。

`grounding.py` 的第16版审计增加局部复核：首次核验结构有效后，筛出来源不匹配的单元，保留原始 block/unit 编号，只发送这些单元及其原引用资料，并给出每个单元允许使用的 evidence ID。复核通过就保留正文；确认原引用缺少支持时，进入既有局部正文修正及再次核验。未出现来源冲突时保持原调用次数。

每批最多增加一次引用复核，复用整次核验的超时和运行 Token 预算；批次并发仍限制为2。复核输出仍校验覆盖范围、真实证据编号、原文引文和每个单元的来源绑定。来源事实不能借常识或非事实标签逃过现有规则。

复核仍选错来源时，不自动更换正文引用，也不把它判为已证实的事实错误；审计记为 `citation_unverified`，保留其他已核验内容，并提示“部分内容的引用尚未核对清楚，已省略该部分”。超时、权限、取消、未知证据、缺失单元继续走原有边界；草稿未核验通过时仍不交付保存审批。

审计保存原文位置、正文 citation IDs、核验 evidence citation IDs、复核阶段与结果。`citation_rechecks` 最多保存64项，每组引用最多16个、每个ID最多256字符；不保存被拒绝的正文、摘录或模型自由评语。旧审计未记录这些字段，无法据此恢复历史请求的具体错引编号。

验证入口：`tests/test_grounding_citation_recheck.py` 覆盖原引用正确、确实缺少支持、反复错源、超时、未知证据、越界单元、修正后复核、取消/权限和诊断范围。`scripts/grounding-citation-smoke.py` 注入首次错误选源后，使用真实模型复核两组纯合成资料；不写用户会话或数据库。该检查不代表真实模型在所有资料上的准确率。

2026-10-29：133项核验回归测试、18项前端流状态测试、类型检查和生产构建通过。真实模型复核2次，分别得到原引用支持/缺少支持的预期结果。Agent 已通过空闲保护重启，HTTP及 Java→Agent RPC 检查通过。
