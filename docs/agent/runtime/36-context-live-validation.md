## 发现和处理

- 真实组件调用曾发现核验层缺少当前用户原话及已确认任务要求，导致正确的任务确认被当作无依据内容。已加入核验事实，排除助手提议；外部事实仍需外部证据，核验版本为 15。
- 未执行公开检索的普通任务确认，曾附加“未找到公开资料”提示。现在只有实际公开检索或引用才触发对应提示。
- `temp/context-http-live-20261023-3/report.json` 保留一次真实格式失败：信息正确，但模型把要求填写文字的 JSON 字段展开成数组。已补充“历史要求是待复述数据，本轮明确输出结构优先”规则；原查询未放宽，最终连续三次 JSON 回忆通过。这仍不是任意提示下格式遵从的数学保证。
- `temp/context-http-live-20261023-4/report.json` 保留重启后首个请求的 HTTP 502。Java 日志显示旧 RPC 连接进入失效列表并重建，随后五轮正常。Agent `/health` 成功不等于 Java → Agent RPC 已恢复；重启脚本的跨服务就绪检查尚待完善。
- 本地服务曾随工具执行会话退出。此次通过无触发器、无提权的临时手动后台启动任务恢复服务，成功后已移除这两次临时任务注册，保留服务进程；没有设置定时或开机触发。

## 复现

服务运行后，从仓库目录执行，输出目录必须尚不存在：

```powershell
$env:PYTHONPATH='python-agent'
$env:PYTHONUTF8='1'
.\python-agent\.venv\Scripts\python.exe -m evaluation.context_live --phase standard --output temp/context-live-new-standard
.\python-agent\.venv\Scripts\python.exe -m evaluation.context_live --phase long --output temp/context-live-new-long
.\python-agent\.venv\Scripts\python.exe -m evaluation.context_http_live --output temp/context-http-new
```

前两项会产生真实模型费用但不写业务数据；第三项需要本地完整服务链，创建并清理独立账号。报告只证明上述场景；大规模并发、多模态长对话、文章写作及跨进程压缩落库仍需分别验证。
