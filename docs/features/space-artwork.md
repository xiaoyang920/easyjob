# 个人空间原创装扮

## 头像挂件交稿规格

[下载「翠鸟衔春」验收样稿（512 × 512 透明 PNG）](../assets/examples/kingfisher-pendant.png)。这份样稿由 AI 辅助生成，使用与运营上传相同的入口和校验；安装迁移不会自动发布商品。

设计师在外部工具完成作品。在后台「装扮商品管理 → 上传头像挂件」下载 SVG 对位模板。画布为 512 × 512，头像圆心为 (256, 256)，直径为画布宽的 60%（307.2），含头像自身边框。导出时隐藏参考线。图案可跨过圆边；请给脸部留出可见区域。头像和挂件始终同心。桌面头像直径 120px 时作品宽 200px；手机 80px 和 70px 时分别约 133px 和 117px。各作品共用这一比例。

交付静态 PNG 或 WebP，正方形，边长 256–1024px，最大 3 MiB。需要实际透明区域和可见画面。动画文件会被拒绝。后台预览把头图、头像和昵称放在同一张资料卡上。可以切换日间和夜间底色，以及三种头像尺寸，检查作品是否遮脸或覆盖昵称。上传说明、对位模板、渲染比例和服务端校验读取共同的 [挂件规格](../../contracts/space-pendant.json)。佩戴时挂件独占头像装饰层，原框的描边、阴影和徽记一起隐藏。挂件不接收指针事件。其他部位保留个人搭配。

## 发行和权益

作品登记名称、作者、部位、素材。商品关联作品，允许同一作品分别进入单品和套装。每个套装每个部位最多一件。用户拥有的作品取全部已购商品所含作品的并集。购买套装按标价收取硬币，已拥有其中的作品时，购买前显示重叠数量和全价。已通过套装获得的单品可直接佩戴。购买重试沿用商城请求编号。已发行作品保留原素材和关联，可下架商品，购买者仍可佩戴。

管理员上传、填写作者、预览、保存作品，再选择单件或套装并定价上架。用户可在商城的「头像挂件」分类试穿，购买后直接佩戴，也可以在装扮页单独佩戴或摘下。后台「作品与组件」可更正作品名与作者，商品标题在商品列表维护。未售出的作品可在关联商品全部下架后撤回。已通过单卖或套装售出的作品保留在库，购买者继续享有使用权。验收时使用两份不同轮廓的作品走相同流程，分别检查访客视图、手机尺寸、下架后佩戴和重复购买账单。第 20 件作品与第 1 件使用同样的发布流程。

## 后续部位约定

本次交付头像挂件。后续新增部位按以下约定接入。

| 部位 | 设计及优先级 |
| --- | --- |
| 头图 | 默认 16:9，另提供 21:9、3:2、4:3 和取景位置。提供「个人照片 / 已购作品」来源选择。使用个人照片时展示最近审核通过的版本；使用作品时展示佩戴的高清图。两者都未选时回落到皮肤头图。 |
| 空间卡片 | 统一 512 × 512 九宫格模板，四条切线距各边 64px，中心透明并继承日夜纸色，边角绘制在装饰区。前端以固定切片渲染；边缘随卡片延展。 |
| 图标包 | 每个语义位置各交日间、夜间两份透明素材，两种模式分别预览。 |

每件原创作品接管自己所在部位。切换旧皮肤时保留佩戴的原创挂件；保存配色和旧组件时也会保留挂件。在「头像挂件」里点「摘下挂件」后，原来选好的头像框会重新显示。佩戴含新挂件的套装则切换到套装里的作品。没有替换的旧部位仍按原搭配展示。

## 开发验收

迁移 `041_space_artwork.sql` 新增三张表。作品表 `space_artwork` 保存作品 ID、部位、名称、作者和原稿地址。商品关联表 `space_product_artwork` 通过 `standalone` 区分单卖与套装收录，并限制一件作品只能建立一个单卖商品。佩戴表 `user_equipped_artwork` 以用户和部位为主键。迁移 `042_space_artwork_management.sql` 给作品增加 `version` 和 `withdrawn`，分别用于并发编辑和撤回。迁移 `043_avatar_pendant_slot.sql` 将作品、商品关联和佩戴记录里的挂件部位统一改为 `avatarPendant`。接口在 `equippedArtworks.avatarPendant` 返回当前挂件，`spaceSkinDress.avatarFrame` 对应旧头像框。硬币流水和商品购买记录沿用现有表。已有开发库可使用本地启动脚本的 `-Migrate` 参数应用迁移及 Blog 账号权限。
