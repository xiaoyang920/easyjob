# 管理后台

## 部署和入口

后台界面位于 Vue 的 `/admin` 路由，接口位于现有 Spring Boot 的 `/api/admin/**`，复用登录、数据库和索引更新链路，不增加服务进程。管理员打开导航栏头像卡片后，可以点击“管理后台”；本地地址为 `http://127.0.0.1:3000/admin`。

当前管理员沿用项目已有定义：`user_info.role=2` 且 `status=1`。页面入口只负责展示，每一个后台接口都会从数据库重新校验权限；普通用户返回 403，未登录返回 401。

## 本次功能

- 概览：注册用户数、已发布文章数、有阅读门槛的文章数、下架文章数、累计有效阅读时长，以及当前阅读等级规则。
- 文章管理：标题或作者搜索、状态筛选、分页、设置阅读等级、下架和恢复已发布文章。
- 文章审核：审核完整提交版本，查看提交时的公开基准对照，支持通过与填写原因驳回。实现细节见 [文章版本审核](../articles/article-reviews.md)。
- 用户与成长：按昵称或用户 ID 查询角色、账号状态、阅读等级及累计有效阅读时长。本版为只读查询。
- 操作日志：记录文章等级、状态变更的操作人、时间和修改前后值。

用户角色、账号封禁和阅读等级阈值编辑未纳入本版界面。

## 文章状态与并发

文章状态为 `0=草稿`、`1=已发布`、`2=已下架`。管理员只能在 1 和 2 之间切换，不能将草稿直接发布。下架后不会进入草稿箱；恢复保留原发布时间与阅读门槛。

修改接口携带页面读取时的 `expectedLevel` 或 `expectedStatus`。服务先按文章主键加行锁，再校验预期值；过期操作返回 409，页面刷新数据供用户重新确认。文章状态、作者已发布文章计数、索引更新 outbox 和审计记录在同一事务提交；事务提交后清理详情与个人空间缓存。重复设置相同状态不重复调整计数。

账号状态在 JDBC 查询中明确转换为数值，避免 MySQL BIT 返回布尔值导致界面把正常账号误判为禁用。列表不返回文章正文、用户密码或邮箱，长整型 ID 以字符串返回，避免浏览器精度丢失。搜索中的 `%` 和 `_` 按字面值处理。

## 数据库与验证

新增迁移 `python-agent/migrations/011_admin_console.sql` 创建 `admin_operation_log` 表。通过已有迁移入口执行，保留原有数据：

```powershell
cd python-agent
.venv\Scripts\python.exe -m app.migrate
```

真实接口专项检查位于 `scripts/admin-console-check.py`，使用临时用户、分类和文章，结束后按测试标识清理，并在 `logs/evaluation` 保存 JSON 报告：

```powershell
python-agent\.venv\Scripts\python.exe scripts/admin-console-check.py
```

该脚本需要本地 Java、MySQL 与 Elasticsearch 已启动，覆盖访问权限、分页筛选、敏感字段缺省、阅读等级、下架恢复、作者计数、过期操作、事务审计和 10 路并发下架。`--preview` 会等待浏览器检查完成后再清理临时数据。
